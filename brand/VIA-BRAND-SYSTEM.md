# VIA — Brand System v1

## Brand idea
**The Franchise Economy, Connected.**

VIA is positioned as the connection layer of the global franchise economy: helping opportunity, people, intelligence and expansion become easier to discover, evaluate and connect.

## Brand personality
Strategic · Connected · Intelligent · Confident · Human · Progressive · International

## Core architecture
**Discovery → Connection → Intelligence → Expansion → Growth**

These five pillars describe the VIA ecosystem and should remain visually consistent across future products, content and experiences.

## Logo system
### Primary
Use the VIA wordmark with the connected V/A route symbol on light backgrounds.

### Reverse
Use the same mark in warm sand/white on Deep Teal backgrounds.

### Symbol
Use the standalone path symbol for favicon, social avatar, app icon and compact placements.

### Clear space
Maintain clear space around the logo equal to at least the height of the coral connection dot.

### Do not
Do not stretch, rotate, add effects, redraw the route, change the dot position, or introduce gradients into the master mark.

## Color system
| Token | Hex | Role |
|---|---|---|
| Deep Teal | #083F40 | Primary brand / authority |
| Living Teal | #087C7C | Connection / digital surfaces |
| Aqua | #42C9BD | Secondary signal / movement |
| Coral | #E07A5F | Opportunity / action / focal accent |
| Mauve | #7A4B6E | Intelligence / differentiation |
| Warm Sand | #E9D8B4 | Premium warmth / editorial accent |
| Paper | #FBF8F2 | Main light background |

Coral and Mauve are signal colors. They should be used deliberately rather than as dominant page fills.

## Typography
**Primary:** Manrope — headlines, UI, body copy.

**Utility:** DM Mono — labels, metadata, numbers, navigation microcopy.

Optional editorial accent: a restrained serif italic may be used only for emphasis words such as *way*, *possibility* and *progress*.

## Signature visual language
The **VIA Path** is the proprietary visual device. It represents a route through opportunity, connection and expansion.

Rules:
- Prefer one continuous route over multiple decorative lines.
- Use nodes sparingly to mark meaningful moments.
- Coral identifies the active opportunity or decision point.
- Rings/orbits should support the idea of connected markets, not become generic tech decoration.
- Avoid generic globe/network imagery.

## Verbal identity
Tone: clear, intelligent, optimistic, commercially grounded.

Avoid: hype, empty startup language, exaggerated scale claims, unsupported statistics, and generic consulting language.

Preferred phrases:
- The franchise economy, connected.
- Connecting franchise. Enabling expansion.
- Where ambition finds its way.
- Every route to growth, made visible.
- From possibility to progress.

## Digital principles
The website should feel like a global ecosystem before it feels like software. Brand-led editorial sections should be visually distinct from future platform UI.

Never present placeholder metrics as live data. Use conceptual labels until real VIA data exists.

## Application priorities
1. Master logo + symbol
2. Website / digital product
3. Social avatar and templates
4. Presentation and proposal system
5. Event / exhibition graphics
6. Business cards and stationery
7. Motion identity

## Ownership principle
The combination of the connected V/A route, single coral node, Deep Teal foundation and restrained editorial typography is the core recognizable VIA system. New creative should extend this system rather than invent a new visual language each time.
